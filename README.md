# Data Structures and Algorithms

A collection of **Data Structures and Algorithms (DSA)** implementations written primarily in **C++**.

This repository contains implementations of **important algorithms and fundamental data structures** commonly used in **Programming, Problem Solving, Competitive Programming, and Technical Interviews**.

The main purpose of this repository is to maintain a growing collection of DSA implementations while building a strong understanding of how these concepts work and how they can be applied to solve programming problems.

---

The repository covers important concepts from **Data Structures and Algorithms**, including:

### 🔹 Graph Algorithms

* Graph Representation
* Shortest Path Algorithms
* Minimum Spanning Tree (MST)
* Dijkstra's Algorithm
* Bellman-Ford Algorithm
* Prim's Algorithm
* Kruskal's Algorithm
* Disjoint Set Union (DSU)

### 🔹 Data Structures

* Graphs
* Disjoint Set Union

* Other data structures that will be added over time

### 🔹 Problem-Solving Algorithms

The repository contains implementations of important algorithms that serve as building blocks for solving programming and competitive programming problems.

More algorithms and data structures will be continuously added as the repository grows.
